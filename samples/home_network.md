# Home Network Notes

## Router
- Router: TP-Link Archer AX55 in the living room. Admin page at http://192.168.0.1.
- Firmware last updated on 2 October 2026.
- The guest Wi-Fi network is called "Rumah-Guest" and is limited to 20 Mbps.

## Devices with fixed IPs
- NAS (Synology DS224+): 192.168.0.10, backups run every night at 02:00.
- Printer (Brother HL-L2350DW): 192.168.0.20.
- Home Assistant on a Raspberry Pi 5: 192.168.0.30, port 8123.

## Troubleshooting
- If the internet drops, restart the fibre modem first, wait 2 minutes, then the router.
- ISP support hotline is saved in my phone under "Unifi Support".
